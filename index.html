01 / 03 — Caso de estudio

Portal de Becarios ASONOG

Rol Full-Stack Developer
Tipo Aplicación web · ONG
Estado En producción
Cliente ASONOG

El problema

ASONOG gestiona programas de becas, pasantías y voluntariados para jóvenes en Honduras. La información de los beneficiarios, las postulaciones y el registro de donaciones se gestionaban de forma manual y dispersa, sin una plataforma centralizada que unificara esos procesos.

La solución

Desarrollé una plataforma web completa que centraliza la gestión de todos los programas de ASONOG. Los postulantes pueden crear cuentas, completar sus postulaciones y consultar el estado. Los administradores gestionan beneficiarios, documentos y donaciones desde un panel único.

Mi contribución

  • Diseño e implementación de la arquitectura de la aplicación con Laravel
  • Modelado y creación de la base de datos
  • Sistema de autenticación y roles de usuario (postulantes / administradores)
  • Integración con PayPal API para el procesamiento de donaciones
  • Panel administrativo para gestión de beneficiarios y documentos
  • Diseño de la interfaz con Tailwind CSS

Funcionalidades principales

  • Registro y autenticación de usuarios
  • Perfiles de becarios con gestión de documentos
  • Postulaciones para becas y pasantías
  • Procesamiento de donaciones vía PayPal
  • Panel de administración completo
  • Control de acceso por roles

Implementación técnica

  • Laravel: Framework principal del backend — rutas, controladores, modelos y autenticación
  • MySQL: Base de datos relacional para toda la información del sistema
  • PayPal API: Integración con webhooks para verificar el estado de los pagos en tiempo real
  • Tailwind CSS: Diseño responsive y accesible

Retos y decisiones

  • Integración con PayPal API — Primera integración con un procesador de pagos real. Estudié la documentación del SDK, configuré webhooks para verificar el estado de los pagos y manejé los distintos estados de las transacciones correctamente.
  • Sistema de permisos granular — Los administradores necesitaban distintos niveles de acceso según el área que gestionan. Implementé roles y políticas de autorización en Laravel para controlar el acceso a cada sección del panel.

Resultado

La plataforma digitalizó un proceso que antes era completamente manual, permitiendo que ASONOG gestione sus programas de becas, pasantías y voluntariados desde una sola aplicación web accesible en línea.

02 / 03 — Caso de estudio

Cotizador de Pérgolas

Rol Full-Stack Developer
Tipo Aplicación web · Empresa
Estado En producción
Cliente Estudio 3A

El problema

El proceso de cotización de proyectos de pérgolas dependía de un archivo de Excel con fórmulas complejas para calcular materiales, dimensiones y precios. Era difícil de mantener cuando cambiaban los precios, propenso a errores al copiarlo entre dispositivos y no era fácilmente accesible para todo el equipo.

La solución

Trasladé toda la lógica de cálculo del Excel a una aplicación web. Con Laravel Livewire, los resultados se actualizan en tiempo real mientras el usuario completa el formulario, sin necesidad de recargar la página. La aplicación es accesible desde cualquier dispositivo con conexión a internet.

Mi contribución

  • Análisis de las fórmulas del Excel original para traducirlas a lógica de aplicación
  • Desarrollo completo de la aplicación con Laravel y Livewire
  • Implementación de los cálculos en tiempo real con componentes Livewire
  • Diseño de la interfaz con Tailwind CSS
  • Configuración del servidor y deployment

Funcionalidades principales

  • Formulario de cotización con parámetros configurables
  • Cálculos automáticos en tiempo real con Livewire
  • Visualización detallada de materiales y costos
  • Interfaz responsive accesible desde cualquier dispositivo

Implementación técnica

  • Laravel: Framework del backend y estructura de la aplicación
  • Livewire: Para la reactividad en tiempo real sin escribir JavaScript separado
  • MySQL: Persistencia de datos y configuraciones
  • Tailwind CSS: Interfaz responsive y consistente

Retos y decisiones

  • Traducir las fórmulas del Excel a lógica de aplicación — Algunas fórmulas tenían dependencias complejas entre celdas que no eran evidentes a primera vista. Tuve que analizar el archivo cuidadosamente, entender la lógica de negocio detrás de cada cálculo y replantear la estructura para que funcionara correctamente en el contexto web.

Resultado

El proceso de cotización, que antes requería abrir un archivo Excel específico y actualizarlo manualmente, ahora se puede completar directamente desde el navegador con resultados automáticos e inmediatos, desde cualquier dispositivo.

03 / 03 — Caso de estudio

Plataforma de Consulta de Facturas

Rol Full-Stack Developer
Tipo Plataforma web
Estado En producción
Cliente UMASGL

El problema

UMASGL necesitaba una forma más accesible para que sus usuarios pudieran consultar la información de sus facturas de agua. La información de facturación se encontraba en archivos de Excel, por lo que era necesario transformar esos datos en información estructurada y disponible para consulta desde una plataforma web.

La solución

Desarrollé una plataforma web que permite a los usuarios consultar la información de su factura de agua ingresando únicamente su clave de cliente. El sistema cuenta además con un panel administrativo desde el cual se pueden cargar los archivos de Excel utilizados por UMASGL.

Al cargar un archivo, la plataforma procesa y extrae automáticamente la información, la estructura según el modelo de datos del sistema y la almacena en la base de datos para que posteriormente pueda ser consultada por los usuarios.

Mi contribución

  • Desarrollo completo de la plataforma con Laravel
  • Diseño e implementación de la estructura de la base de datos
  • Desarrollo del sistema de consulta mediante clave de cliente
  • Desarrollo del panel administrativo
  • Implementación del proceso de importación de archivos Excel
  • Procesamiento y transformación de los datos antes de almacenarlos
  • Integración del flujo completo entre carga, procesamiento y consulta de información

Funcionalidades principales

  • Consulta de información de facturación mediante clave de cliente
  • Panel de administración para gestionar la información
  • Carga de archivos Excel con datos de facturación
  • Extracción y procesamiento automático de datos
  • Almacenamiento de la información procesada en la base de datos
  • Disponibilidad de la información para consulta desde la plataforma web

Implementación técnica

  • Laravel + PHP: Backend, lógica de negocio y estructura de la aplicación
  • MySQL: Almacenamiento estructurado de la información de facturación
  • Excel: Fuente de datos utilizada para actualizar la información del sistema
  • Importación de datos: Procesamiento y transformación de la información proveniente de los archivos Excel utilizando la libreria Laravel Excel.

Resultado

La plataforma convirtió un proceso basado en archivos de Excel en un sistema web de consulta. Los administradores pueden actualizar la información mediante la carga de nuevos archivos, mientras que los usuarios pueden acceder directamente a los datos de su factura utilizando su clave de cliente.
